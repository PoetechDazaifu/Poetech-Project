# 本番運用方針

## 監視

RenderのHTTPヘルスチェックは`/healthz`を使用する。デプロイ後にこのエンドポイントが2xxを返すことを確認し、5xxが継続する場合は直前の正常なデプロイへロールバックする。

## セキュリティ

アプリケーションはCSP、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`を返す。ワードクラウド生成はプロセスごと・送信元IPごとに1分間20回までとする。Cloudflare等のリバースプロキシを導入する場合は、プラットフォームのWAF・レート制限を前段の防御として併用する。

## データとログ

元データに含まれる詳細な`在住地`はDBにだけ保持し、公開APIと画面には`居住地分類`のみを返す。アクセスログやエラー監視を新たに導入する場合は、IPアドレスを含むログを30日以内で削除する設定にし、個人が特定できる情報をログへ追加しない。
